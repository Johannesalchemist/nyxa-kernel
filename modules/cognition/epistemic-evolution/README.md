1. **Epistemic Self-Model** — `classify()`: verifiziert, kontextabhängig, Inferenz, Hypothese, erkanntes Nichtwissen, widersprüchlich, vermuteter blinder Fleck, kooperativ erschließbar; `metacognition()` macht die Einschätzung des eigenen Nichtwissens messbar.
2. **Question Evolution** — Fragen aus Erfahrung, Widerspruch, Lücke, Überraschung, Analogie, Beziehung; Bewertung (Relevanz, Erkenntnispotenzial, Beantwortbarkeit, Nutzen, Kosten); Portfolio mit Budget und Side-Quest-Filter.

4. **Actionable Knowledge** — Question → Evidence → Answer → Options → Preconditions → Implementation → Verification → Experience; Lernsignal aus verifizierter Wirkung; ungovernte Effekte werden markiert.
5. **Experience Space Expansion** — interne Gelegenheiten (Simulation, Retrospektive, Perspektivwechsel, Analogie, Selbsttest) frei; alles Externe ist governed action. Neugier autorisiert nichts.
